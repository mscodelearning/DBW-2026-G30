# Configuração a ser feita para a execução do projeto
Apos descarregar o projeto abrir o terminal/consola e executar o comando 
    'node index.js'  +  enter 

De seguida abrir um browser e pesquisar o seguinte url
    'http://localhost:3000/'
esta acao abrirá a pagiana web da aplicacao desenvolvida e agora esta tudo pronto para comecar a explorar a aplicacao
